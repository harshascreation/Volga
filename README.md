# Volga

Volga is a responsive image-search app. Search for a topic or choose one of the quick-pick chips to find images from Wikimedia Commons.

## Features

- Loading feedback while an image search is in progress.
- Friendly empty and error messages instead of a blank results area.
- A result count and subtle card entrance animation.
- Responsive layout with reduced-motion support.

## Run locally

Open `index.html` in a browser. The app uses the Wikimedia Commons public API and requires an internet connection to search.

## Deploy

This is a static site and can be deployed from the repository root using GitHub Pages, Netlify, or Vercel. On GitHub, enable Pages in the repository settings and select the branch and root folder containing `index.html`.
